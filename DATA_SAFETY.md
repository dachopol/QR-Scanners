# Google Play Data Safety Declaration

**App Name:** QR Scanners
**Package:** com.anakinyoo.qrscanners

- **Data Collection:** No user data collected.
- **Data Sharing:** No user data shared with third parties.
- **Security Practices:** No data transmitted over the internet. Storage is sandboxed in private app directories.
- **Permissions:**
  - `CAMERA`: Optional runtime permission used only for real-time code scanning.
  - `VIBRATE`: Normal install permission for haptic feedback.
